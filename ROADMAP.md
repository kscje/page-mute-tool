# Roadmap

This file tracks ideas for future versions. Items here are not committed release promises.

## Backlog

- Add a manual language selector in the options page.
- Add rule search and filtering for large domain lists.
- Add import preview before applying imported domain rules.
- Add per-domain block statistics.
- Add duplicate handling options during import.
- Add a lightweight onboarding screen for first-time users.
- Add more locale files if user demand appears.

## Possible v1.0.x Maintenance

- Fix Chrome Web Store review feedback.
- Improve edge-case handling for special page URLs.
- Refine store screenshots and copy after launch.

## Possible v1.1.0 Features

- Rule search in options page.
- Import conflict preview.
- Optional per-domain descriptions in popup view.
- Export selected domains only.
