# Changelog

All notable changes to Page Mute Tool are documented here.

## v1.0.1 - 2026-05-08

- Fixed the Chrome Extensions management page icon by adding top-level extension icons to the manifest.

## v1.0.0 - 2026-04-28

- Added domain-based media autoplay blocking for audio, video, and iframe media.
- Added popup support for viewing the current domain and quickly adding it to the managed domain list.
- Added options page domain management with exact and wildcard domain rules.
- Added import, export, clear, delete, and enable/disable controls for domain rules.
- Added toolbar icon state switching based on whether the current domain is active.
- Added Simplified Chinese and English localization with automatic browser-language detection.
- Added Chrome Web Store package and listing assets.
- Added local-only storage for rules, settings, and blocking statistics.
