# 网站自动播放拦截器隐私政策

最后更新日期：2026-04-27

网站自动播放拦截器是一款 Chrome 扩展，用于阻止用户指定域名上的媒体自动播放。

## 插件使用的信息

插件仅使用当前页面的 URL 和域名来判断用户保存的域名规则是否应在当前网站生效。

插件会存储以下信息：
- 用户添加的域名规则；
- 可选的域名描述；
- 插件设置；
- 本地拦截统计。

## 信息用途

这些信息仅用于实现插件的单一用途：在用户指定的域名上阻止媒体自动播放，并显示当前域名是否处于启用状态。

## 数据共享

网站自动播放拦截器不会出售、传输或与第三方共享用户数据。

插件不使用分析、广告、跟踪功能，也不会连接远程服务器。

## 数据存储

域名规则和设置通过 Chrome storage API 保存。拦截统计保存在浏览器本地。

## 远程代码

网站自动播放拦截器不会加载或执行远程托管代码。
