# Chrome 应用商店上架文案草稿

## 基本信息

名称：
Page Mute Tool

简短说明：
按域名阻止网页媒体自动播放，让音频和视频播放回到你的控制中。

详细说明：
Page Mute Tool 可以帮助你阻止指定网站中的媒体自动播放。你可以在插件弹窗中快速添加当前域名，也可以在设置页集中管理域名规则。插件会在你与页面交互前保持音频和视频静音/暂停，减少网页自动播放带来的打扰。

主要功能：
- 在工具栏弹窗中一键添加当前网站域名。
- 在设置页管理精确域名和通配域名规则。
- 在用户交互前阻止音频、视频和 iframe 中的媒体自动播放。
- 在设置页导入、导出和清空域名规则。
- 根据当前域名是否已启用，自动切换工具栏图标状态。
- 使用 Chrome storage 在本地保存设置；不包含远程追踪或分析功能。

## 语言

## 隐私实践

用途：
插件仅使用当前页面 URL/域名来判断用户添加的域名规则是否应在当前网站生效。

数据处理：
- 域名规则和设置使用 `chrome.storage` 保存。
- 插件不会收集、出售、传输或与任何远程服务器共享浏览数据。
- 插件不使用分析、广告或外部网络请求。

主机权限说明：
`<all_urls>` 权限用于让内容脚本能够在用户添加到受管控列表的网站上检测并阻止媒体自动播放。

存储权限说明：
`storage` 权限用于保存域名规则、设置和本地拦截统计。

当前标签页权限说明：
`activeTab` 权限用于读取当前标签页上下文，以支持添加当前域名、刷新当前页面状态等弹窗操作。

## 推荐手动测试说明

- 在 Chrome 中加载未打包扩展。
- 添加一个匹配域名，并确认用户交互前自动播放会被阻止。
- 测试一个不匹配域名，并确认插件保持未启用状态。
- 确认工具栏图标会在启用和未启用状态之间切换。
- 确认弹窗中的添加和删除域名功能正常。
- 确认设置页中的导入、导出、清空和域名启用/停用功能正常。
